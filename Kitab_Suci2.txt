BAGIAN II: TECH STACK
═══════════════════════════════════════════════════════════════════════════════

Frontend:
  - Next.js 16 (App Router, React 19, Server Components)
  - Tailwind CSS v4 (utility-first, CSS @theme directives)
  - shadcn/ui (component library, manually adapted for Tailwind v4)
  - Lucide React (icon library)

Backend:
  - Next.js Server Actions (for form submissions)
  - Next.js Route Handlers (for API endpoints)
  - JWT Auth via `jose` library (custom, no Supabase Auth)
  - Rate limiter: in-memory (`src/lib/rate-limit.js`)

Database:
  - PostgreSQL 15+ (self-hosted)
  - Schema: `app` (not `public`)
  - Connection: `pg` (node-postgres) with connection pooling
  - Migration system: SQL files in `/migrations/`, run via `scripts/migrate.js`

Email:
  - Resend API (`RESEND_API_KEY`)
  - Templates: OTP, welcome, role change, comment notification, etc.

Media:
  - Cloudinary (unsigned upload preset for admin)
  - Google Drive image normalization (`getDisplayUrl`)

Deployment:
  - Vercel (Washington D.C. region)
  - Self-hosted PostgreSQL (any VPS with SSL/TLS)
  - Environment variables via Vercel Dashboard

BAGIAN VIII: DEPLOYMENT GUIDE (Vercel + Self-Hosted PostgreSQL)
═══════════════════════════════════════════════════════════════════════════════

PRE-DEPLOYMENT:
  1. Push semua perubahan ke GitHub (branch main)
  2. Pastikan PostgreSQL server aktif & menerima koneksi SSL
  3. Set semua environment variables di Vercel Dashboard
  4. Jalankan migration ke production database:
     npm run migrate   (atau manual via psql/HeidiSQL)
     Urutan: migration.sql → migration-v2.sql → ... → migration-v16.sql

VERCEL DEPLOYMENT:
  1. Vercel Dashboard → Deployments → Trigger Deployment (branch main)
  2. Build akan: npm install → node scripts/migrate.js → next build
  3. Migration script akan skip jika DB tidak tersedia (build tetap lanjut)
  4. Jika deploy sukses, Vercel akan serve aplikasi

  Build Machine: Washington D.C., USA (East) — iad1
  Plan: Hobby (2 cores, 8 GB)

POST-DEPLOYMENT:
  1. Cek /home apakah loading normal
  2. Cek /login → login sebagai admin
  3. Cek /admin → dashboard admin
  4. Cek email: register akun baru → verifikasi OTP
  5. Cek database: pastikan page_view_logs terisi

NOTES:
  - Build akan fail jika ada ESLint error: npm run lint dulu
  - Pastikan DATABASE_URL pakai connection pooler untuk production
  - Self-hosted PostgreSQL harus allow koneksi dari IP Vercel
  - Rate limiter in-memory (single instance OK untuk hobby plan)
  - Multi-replica perlu Redis/Upstash untuk rate limiting

BAGIAN X: TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Q: Page 500 error setelah deploy?
A: Cek Vercel Dashboard → Function Logs. Biasanya:
   - Database connection (pool exhausted): cek DATABASE_URL + connection pooler
   - Missing table/column: jalankan migration yang sesuai
   - Build error: cek npm run lint lokal

Q: "remaining connection slots are reserved"
A: Database pool penuh. Solusi:
   - Kurangi `max: 10` di src/lib/db.js jadi 4-5
   - Pakai connection pooler (PgBouncer)
   - Tutup koneksi idle yang tidak perlu

Q: Email tidak terkirim?
A: - Cek RESEND_API_KEY valid
   - Cek EMAIL_FROM sudah verified di Resend dashboard
   - Cek domain sudah setup DNS records

Q: Dark mode tidak berfungsi?
A: - Cek class "dark" ada di <html> — localStorage.getItem("theme")
   - Cek @custom-variant dark di globals.css
   - Cek ThemeToggle.js useEffect berjalan

Q: Gagal build karena migration?
A: - Migration error sudah non-fatal (build tetap lanjut)
   - Jika tetap error: comment dulu baris `node scripts/migrate.js` di package.json
   - Jalankan migration manual via HeidiSQL/psql

Q: Login tidak bisa?
A: - Cek AUTH_SECRET sudah set
   - Cek DATABASE_URL bisa konek
   - Cek tabel accounts ada isinya

Q: fitur admin tidak muncul?
A: - Pastikan login sebagai admin (role = "admin")
   - Cek session cookie tidak expired
   - Cek proxy.js tidak block request

Q: Halaman pake var(--) masih ada?
A: - Sudah semua diganti Tailwind utility classes
   - Jika ada sisa: cari "var(--" di src/ (kecuali select.jsx & globals.css)
