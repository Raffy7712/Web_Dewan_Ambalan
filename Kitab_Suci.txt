   email escape HTML, session JWT issuer/audience, banned account gate.

BAGIAN VIII: MEDIA UPLOADS & CLOUDINARY INTEGRATION (May 2026)
═══════════════════════════════════════════════════════════════════════════════

MASALAH AWAL:
- Google Drive share links (uc?export=view) return 403 Forbidden dari browser non-authenticated.
- File di Drive hanya bisa di-access jika user sudah login ke Google account.
- Solution: Gunakan public image hosting service.

SOLUSI TERPILIH: Cloudinary
✅ Alasan:
  - 10GB free storage (vs Firebase 1GB/bulan)
  - Upload widget built-in (drag & drop)
  - API JavaScript untuk direct upload dari browser
  - Image optimization & CDN otomatis
  - Tidak perlu backend upload handler
  - Scaling mudah (pay-as-you-go)

IMPLEMENTATION ROADMAP:
1. Setup Cloudinary account & env vars
2. Create upload widget component di /admin/posts/new & /admin/posts/[id]/edit
3. Replace Google Drive URL textarea dengan Cloudinary upload dropzone
4. Modify form submission: save Cloudinary URLs ke post_media
5. Update getDisplayUrl() untuk handle Cloudinary URLs

ENV VARIABLES (.env.local):
```
NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME=your_cloud_name
NEXT_PUBLIC_CLOUDINARY_UPLOAD_PRESET=your_upload_preset
CLOUDINARY_API_KEY=your_api_key (optional, for server-side)
```
